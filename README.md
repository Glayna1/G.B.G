# G.B.G — Glayna Better Guild

**Version en cours de publication : 1.8.11** · **World of Warcraft 3.3.5a / Ascension: Conquest of Azeroth** · Interface `30300`

G.B.G remplace la fenêtre de guilde Blizzard par un véritable espace de guilde moderne et synchronisé : discussion persistante, mentions, profils, portraits, Main/rerolls, notes privées, alertes de connexion, bannières personnalisées, invitations, recherche d’activités JcE/JcJ et recrutement inter-guildes.

## Dépôt complet

Le dossier `GBG` contient l’intégralité des sources et médias de l’addon. La publication 1.8.11 est préparée par le workflow GitHub Actions **Publish complete G.B.G 1.8.11**, qui vérifie le paquet, conserve les médias TGA, applique le code 1.8.11 et refuse tout commit incomplet.

## Installation

1. Ouvrez l’onglet **Actions** du dépôt.
2. Sélectionnez **Publish complete G.B.G 1.8.11**.
3. Cliquez sur **Run workflow**, puis confirmez **Run workflow**.
4. Une fois le commit de publication créé, téléchargez le dépôt avec **Code > Download ZIP**.
5. Extrayez et placez uniquement le dossier `GBG` dans :

```text
World of Warcraft\Interface\AddOns\
```

## Commandes

```text
/gbg              Ouvre ou ferme l’interface.
/gbg reset        Réinitialise la position de la fenêtre et du lanceur.
```
